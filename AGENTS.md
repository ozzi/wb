# AGENTS.md

Этот проект — набор скриптов для автоматизации **Wiren Board**.

## Главное

- Основной код проекта находится в папке `rules/`.
- Код в `rules/` предназначен для **wb-rules**.
- Это **не Node.js** и не браузерный JavaScript.
- Использовать стиль и синтаксис, совместимый с **ECMAScript 5**.
- Не использовать современный JS без явного запроса:
  - `let`, `const`
  - arrow functions
  - classes
  - async/await
  - optional chaining
  - destructuring
  - `import` / `export`

## Как вносить изменения

- Делать **минимальный diff**.
- Не делать лишний рефакторинг.
- Не менять существующее поведение без необходимости.
- Не переименовывать устройства, контролы и правила без явного запроса.
- Для нетривиальных задач: сначала короткий план, потом изменения.

## Что учитывать

- Код управляет автоматизацией, поэтому важны предсказуемость и осторожность.
- Избегать неочевидной логики, скрытых побочных эффектов и лишних абстракций.
- Если есть сомнение в API wb-rules — сверяться с документацией.

## Язык общения

- Всегда отвечай пользователю на русском языке.
- Объяснения, планы изменений и комментарии в чате — на русском.
- Код, имена переменных, API и технические термины оставляй в оригинале, если это уместно.
- Не переходи на английский без явного запроса.
