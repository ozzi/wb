# Pool Heat Controller

Контроллер нагрева воды в бассейне.

## Описание

Управляет запросом тепла на основе текущей температуры воды, целевой температуры и состояния фильтрации. Не управляет нагревателем напрямую — выставляет топик `heat_request`, который читает внешний контроллер.

## Использование

    makePoolHeatController(
        name,                          // имя экземпляра
        currentTemperatureTopicName,   // топик текущей температуры воды
        poolFiltrationModeTopicName    // топик режима фильтрации
    );

Создаёт виртуальное устройство `pool-heat-ctrl-<name>`.

## Контролы устройства

| Контрол        | Тип     | R/W | Описание                          |
|----------------|---------|-----|-----------------------------------|
| `mode`         | value   | RW  | 0 — выключено, 1 — нагрев         |
| `target`       | value   | RW  | Целевая температура (°C)          |
| `hysteresis`   | value   | RW  | Гистерезис (°C), по умолчанию 0.5 |
| `current`      | value   | RO  | Текущая температура (°C)          |
| `heat_request` | switch  | RO  | Запрос тепла                      |
| `status`       | value   | RO  | Текущий статус (см. ниже)         |

## Статусы

| Код | Описание                  |
|-----|---------------------------|
| 0   | Выключено                 |
| 1   | Ожидание фильтрации       |
| 2   | Температура достигнута    |
| 3   | Нагрев                    |
| 4   | Ошибка датчика            |
| 5   | Ошибка фильтрации         |

## Логика

- `heat_request = true` только если `mode = 1` и `filtration mode = 1`.
- Нагрев включается при `current < target - hysteresis`.
- Нагрев выключается при `current > target + hysteresis`.
- В зоне гистерезиса состояние не меняется.
- При недоступном датчике или режиме фильтрации `heat_request` сбрасывается в `false`.

## Пример

    makePoolHeatController(
        "outdoor",
        "wb-m1w2_69/External Sensor 1",
        "pool-filtration-ctrl-outdoor/mode"
    );
