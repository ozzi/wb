# Pool Heat Controller

Контроллер нагрева воды в бассейне.

## Описание

Управляет запросом тепла на основе текущей температуры воды, целевой температуры и состояния фильтрации. Не управляет нагревателем напрямую — выставляет топик `heat_request`, который читает внешний контроллер.
