# pool-filtration-controller.js

Контроллер управления насосом фильтрации бассейна.

## Функция `makePoolFiltrationController(name, pumpSwitchTopicName, buttonTopicName, flowSensorTopicName)`

### Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `name` | string | да | Уникальное имя экземпляра (используется в именах устройств и правил) |
| `pumpSwitchTopicName` | string | да | Топик реле насоса (запись `true`/`false`) |
| `buttonTopicName` | string | нет | Топик кнопки MCM8 (для управления через физическую кнопку) |
| `flowSensorTopicName` | string | нет | Топик датчика протока (геркон, нормально разомкнутый, `true` = проток есть) |

### Виртуальное устройство `pool-filtration-ctrl-{name}`

| Ячейка | Тип | Доступ | Описание |
|---|---|---|---|
| `mode` | value (enum) | чтение/запись | Текущий режим работы |
| `flow_check_delay` | value (с) | чтение/запись | Задержка перед проверкой протока (защита от дребезга и время набора давления), по умолчанию 30 с |

### Режимы (`mode`)

| Значение | Название | Описание |
|---|---|---|
| `0` | Off | Насос выключен |
| `1` | Filtration | Фильтрация, насос включён |
| `2` | Backwash | Обратная промывка, насос включён |
| `3` | Fault | Ошибка (нет протока), насос выключен |

### Логика работы

- При переходе в режим `1` (Filtration) насос включается. Если задан `flowSensorTopicName` — запускается таймер на `flow_check_delay` секунд. По истечении таймера, если проток отсутствует (`false`), контроллер переходит в режим `3` (Fault).
- При пропадании протока во время фильтрации таймер перезапускается. При появлении протока — отменяется.
- При переходе в режим `0`, `2` или `3` насос выключается, таймер отменяется.
- Из режима `3` (Fault) выйти можно только вручную, установив `mode = 0` или `mode = 1`, либо физически включив реле насоса.

### Управление кнопкой (если задан `buttonTopicName`)

| Действие | Результат |
|---|---|
| Одиночное нажатие в режиме `0` | Переход в режим `1` |
| Одиночное нажатие в режиме `1` | Переход в режим `0` |
| Одиночное нажатие в режиме `2` | Переключение реле насоса |
| Долгое нажатие | Переключение между режимами `1` и `2` |

### Возвращаемое значение

```js
{ modeTopicName: "pool-filtration-ctrl-{name}/mode" }
```

### Пример использования

```js
var ctrl = makePoolFiltrationController(
    "outdoor",
    "wb-mr6cu_91/K1",
    "wb-mcm8_238/Input 3",
    "wb-mcm8_238/Input 2"
);
```
