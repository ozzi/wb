# Проверка шаблонов Modbus TCP без устройства

Шаблоны `templates/config-*.json` — это не код, а описание регистров для драйвера
`wb-mqtt-serial`. Их не ловит ни один тест wb-rules, а ошибки в них видны только
на живом обмене. Поэтому две проверки: статическая и по обмену.

## Статическая проверка

```bash
node tests/modbus-template-check.js templates/config-victron-solarcharger.json
node tests/modbus-template-check.test.js   # проверка самой проверки
```

Скрипт ищет то, что драйвер проглотит молча, а потом отдаст мусор в MQTT:

- дубль `id` канала — второй канал не появится вовсе;
- неизвестный `format`, `error_value` больше разрядности формата;
- `word_order` у 32-битного регистра (по умолчанию `big`; для 16-битных не применяется);
- перекрытие адресов и выход за 0..65535;
- `max_read_registers` больше предела Modbus 125 и `max_reg_hole` больше 16;
- группировку регистров в запросы по правилам `src/modbus_common.cpp`: регистры
  склеиваются в один запрос через «дыры» размером до `max_reg_hole`, но не длиннее
  `max_read_registers`. Печатается карта запросов — она же подсказывает, что и в каком
  порядке драйвер спросит у устройства.

Проверять надо все шаблоны, а не только новый: скрипт принимает путь файла.

## Проверка по обмену (эмулятор)

Адреса эмулятор не проверяет, он проверяет транспорт, масштабы и порядок слов. Годится,
когда устройство временно недоступно: поднять Modbus TCP-сервер и завести его адрес как
`modbus tcp` с тем же шаблоном.

```python
from pymodbus.datastore import (ModbusSequentialDataBlock, ModbusServerContext,
                                ModbusSlaveContext)
from pymodbus.server import StartTcpServer

ctx = ModbusServerContext(slaves=ModbusSlaveContext(
    hr=ModbusSequentialDataBlock(0, [0] * 400)), single=True)
StartTcpServer(context=ctx, address=("0.0.0.0", 1502))
```

Эмулятор отдаёт нули, поэтому: каналы должны появиться со значением `0` и без
`meta/error` — так ловится `error_value`, совпавший с нормальным значением, и развал
группы запросов. Масштаб на нулях не проверить; для этого в эмуляторе нужно прописать
осмысленные значения в нужные регистры.

Порядок работы: адреса — по документации производителя, транспорт и арифметика —
по эмулятору, смысл значений — по живому устройству. Перепутанный адрес эмулятор
покажет как ноль и «всё зелёное».
