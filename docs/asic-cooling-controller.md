# asic-cooling-controller.js

Контроллер управления ASIC-майнерами для нагрева бассейна. Запускает и останавливает майнеры в зависимости от запроса на нагрев от контроллера бассейна. Поддерживает минимальное время работы майнеров перед остановкой.

## Функция `makeASICPoolHeatController(name, poolHeatRequestTopicName, asicDeviceNames)`

### Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `name` | string | да | Уникальное имя экземпляра |
| `poolHeatRequestTopicName` | string | да | Топик статуса контроллера нагрева бассейна |
| `asicDeviceNames` | string[] | да | Массив имён виртуальных устройств ASIC-майнеров |

### Виртуальное устройство `asic-pool-heat-ctrl-{name}`

| Ячейка | Тип | Доступ | Описание |
|---|---|---|---|
| `min_run_minutes` | value (мин) | чтение/запись | Минимальное время работы майнеров перед остановкой, по умолчанию 30 мин |
| `mining_started_at` | value (ms) | только чтение | Unix timestamp (мс) момента запуска майнинга, `0` если не запущен |

### Константы статусов бассейна

| Константа | Значение | Описание |
|---|---|---|
| `POOL_STATUS_IDLE` | `2` | Бассейн в режиме ожидания — нагрев не нужен |
| `POOL_STATUS_HEATING` | `3` | Бассейн требует нагрева — майнеры должны работать |
| `POOL_STATUS_WAITING_SETTLE` | `6` | Ожидание стабилизации температуры — майнеры не трогаем |

### Логика работы

**При получении статуса `POOL_STATUS_HEATING`:**
- Отменяется таймер отложенной остановки (если был запущен)
- Запускаются все ASIC-майнеры кроме тех, у которых `state == "failure"`
- Фиксируется время запуска в `mining_started_at` (если ещё не зафиксировано)

**При получении статуса `POOL_STATUS_IDLE`:**
- Вычисляется прошедшее время с момента запуска
- Если прошло меньше `min_run_minutes` — запускается таймер на оставшееся время, после которого майнеры останавливаются
- Если прошло достаточно — майнеры останавливаются немедленно
- Если `mining_started_at == 0` (майнеры не запускались этим контроллером) — останавливаются немедленно

**При статусе `POOL_STATUS_WAITING_SETTLE`:**
- Ничего не делаем — ждём пока проток стабилизируется после запуска фильтрации
- Таймер остановки и состояние майнеров не изменяются

**При любом другом статусе** (ошибка, выключено и т.д.):
- Таймер отменяется
- Майнеры останавливаются немедленно

**Управление ASIC-устройствами:**
- Запуск: `dev[asicDevice + "/start_mining"] = true`
- Остановка: `dev[asicDevice + "/stop_mining"] = true`
- Устройства в состоянии `failure` пропускаются при запуске

**Инициализация при старте:**
- `applyHeatRequest()` вызывается сразу при загрузке — контроллер приводится в актуальное состояние

### Пример использования

```js
makeASICPoolHeatController(
    "outdoor",
    "pool-heat-ctrl-outdoor/status",
    ["ANTMINER S21e"]
);
```
